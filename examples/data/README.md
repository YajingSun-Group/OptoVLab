# Demonstration data

These JSON files are intentionally small and are provided only to exercise the
OptoVLab interfaces.

- OLED records summarize examples described in the manuscript draft and are
  labeled `demo_record`.
- OFET and OPV records are synthetic.
- No publisher PDF, private workbook, or third-party dataset is included.

Do not use these records to reproduce reported model metrics or draw scientific
conclusions.
