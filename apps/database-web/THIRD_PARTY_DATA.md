# Third-party data

No third-party research dataset is bundled in this repository. The committed
OLED, OFET, and OPV JSON files are small interface demonstrations described in
`examples/data/README.md`.

The exporter can consume separately obtained datasets, including compatible
OPV browser JSON. Users are responsible for obtaining those data from their
authoritative source, preserving attribution, and complying with the source
license. Generated exports are ignored by default when they contain local
research inputs.
