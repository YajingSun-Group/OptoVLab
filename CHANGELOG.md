# Changelog

## 0.1.0 - 2026-08-25

Initial public research-code release.

- Added the Data Mining, Device Modeling, and Experimental Design agent APIs
  and React workbench.
- Added evidence-linked OLED extraction, material identity/OCSR review, and
  batch mining services.
- Added the directed OLED-GAT quantile-regression implementation and
  explainability tooling.
- Added the OLED/OFET/OPV static database browser with demonstration records.
- Added a responsive GitHub Pages publication demo, CI, release auditing,
  deployment documentation, and citation metadata.
- Excluded publisher PDFs, private datasets, runtime state, credentials, and
  trained checkpoints from the public repository.
